5. STANDAR DESAIN & KUALITAS WEB (WAJIB)
--------------------------------------------------------------------------------
DESAIN
- Premium & intentional: setiap elemen punya tujuan, tolak default generik AI.
- Cinematic & spatial: whitespace masif (py-32), ritme sinematik.
- Konsisten dengan DESIGN.md sebagai design bible.

TEKNIS
- Animasikan HANYA transform & opacity. Larang animasi top/left/width/height.
- CSS Grid untuk layout. min-h-[100dvh], bukan h-screen.
- Lazy load komponen berat; mobile-first; larang horizontal scroll.
- Isolasi UI interaktif dari komponen statis.

TIPOGRAFI & WARNA
- Banned font: Inter, Roboto, Arial. Pakai: Plus Jakarta Sans (current),
  Geist, Outfit, Satoshi.
- Maks 1 warna aksen (<80% saturasi), basis netral (Zinc/Slate).
  Larang pure #000000.

KOMPONEN & MOTION
- Kartu hanya jika elevasi = hierarki. Prefer border-t/divide-y/negative space.
- Interaksi lengkap: loading, empty, error state. Feedback taktil :active.
- Spring physics (stiffness 100, damping 20). Larang linear easing.
- Staggered reveals + micro-interactions perpetual.
- Live data > static data (pola Google Sheets live wajib dipertahankan).

KONTEN ANTI-SLOP
- Banned: emoji dekorasi, marketing klise ("Unleash", "Seamless"), avatar
  generik, label section tanpa makna, ikon/blob tanpa fungsi.
- Wajib: teks readable, klaim didukung angka nyata, copywriting konsisten
  dengan positioning "system builder".

IMAGE-FIRST WORKFLOW (redesign visual):
Generate referensi desain per-section -> analisa mendalam -> implementasi
setia. Jangan drift ke default generik.

BANNED LIST FINAL: gradien ungu/biru AI, 3 kolom kartu identik,
box-dalam-box-dalam-box, pure #000000, mobile above-the-fold cluttered,
animasi non-accelerated.
